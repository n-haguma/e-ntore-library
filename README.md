# e-ntore library

Plain-text skills from the e-ntore library, packaged for any agent that reads a plugin
marketplace. The same items, with their stories, are at https://entore.ai/library.

Add the marketplace, then install a skill:

    /plugin marketplace add n-haguma/e-ntore-library
    /plugin install weekly-review@e-ntore-library

Each skill is one SKILL.md file, licensed CC-BY-4.0. e-ntore users keep them straight
into their vault instead; nothing here requires e-ntore.
